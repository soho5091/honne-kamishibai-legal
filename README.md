# honne-kamishibai-legal

Static legal pages (Privacy Policy / Terms of Service) for the personal tool behind the TikTok account **ほんねの紙しばい** (@honne_kamishibai).

The tool uploads the owner's own AI-generated videos (always labelled as AI-generated) to the owner's own TikTok account via the Content Posting API, private by default. No monetization.
